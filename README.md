### 🚀 Projeto em destaque

**[Task-Scheduler-Optimizer](https://github.com/MarinhoBiel/Task-Scheduler-Optimizer)**
Painel de monitoramento de rotinas agendadas no Windows Task Scheduler.
Inventaria as tarefas, detecta conflitos de horário entre rotinas concorrentes,
identifica falhas de execução pelo código de retorno, calcula atraso de
execução e sinaliza robôs "esquecidos". Classifica automações por tecnologia
(Python, PowerShell, BAT, EXE) e exporta os dados para BI (CSV/Parquet),
além de gerar um relatório completo em Excel.
